# Multi-Agent Workflow Automation

An enterprise-style multi-agent system built with LangGraph.

## Features
- Stateful orchestration
- Scout, Analyst, Strategist, and Auditor agents
- Looping self-correction
- Human approval checkpoint
- Retry handling with Tenacity
- Local logging

## Run
```bat
python -m src.main
```

## Install
```bat
python -m pip install -r requirements.txt
```
